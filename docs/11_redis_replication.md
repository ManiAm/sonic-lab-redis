

### **Replication & Clustering**

| Command       | Description |
|--------------|-------------|
| `PSYNC`      | Partial resynchronization with replicas. |
| `REPLICAOF`  | Set the current server as a replica of another server. |
| `SLAVEOF`    | Deprecated alias for `REPLICAOF`. |
| `SYNC`       | Full synchronization with a replica. |
| `ROLE`       | Show the replication role of the instance (master, replica, or sentinel). |
| `CLUSTER`    | Manage Redis Cluster commands. |
